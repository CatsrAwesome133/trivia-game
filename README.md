# trivia-game
An online trivia game that uses questions from Open Trivia DB

![Image of the game](https://f2.toyhou.se/file/f2-toyhou-se/images/130522033_psfXRqd49BKxqDs.png)

This was made to familiarize myself with Javascript and API usage. 

...also I haven't found many other dedicated trivia games

One of my goals is to make this cleaner than my website. We'll see how I do... 

## How to play
Go to the [github pages website](https://catsrawesome133.github.io/trivia-game/index.html), then follow the instructions on the page!

Remember to not leave questions blank ^^

## How does this work?
Open Trivia DB has an API that returns some helpful JSON data. This program uses that JSON, requested with user settings, to create questions and randomize answers.

Answer selection is done with `onclick` functions.
